# Mini App con Fetch API, ESLint y Husky

Aplicación web desarrollada en JavaScript Vanilla que consume una API pública y filtra los datos dinámicamente.

## Configuración y Calidad de Código
- Se utiliza **ESLint** para mantener los estándares del código.
- Se configuró **Husky** con un hook de `pre-commit` para impedir commits si hay errores de estilo o sintaxis.

## Instrucciones para ejecutar
1. Clonar el repositorio.
2. Ejecutar `npm install` para instalar dependencias.
